# BloodPanel extension

Use the BloodPanel MCP tools when a user asks to find or compare blood tests in
Ireland. Preserve the user's town, Eircode, test wording, date and time
preferences between tool calls. The extension exposes catalogue tools only.
Treat every listing and price as an example because catalogue facts are not
live-verified. Confirm current prices and availability with the provider.

BloodPanel is a catalogue and comparison service. It does not provide medical
advice or diagnosis. Never invent panel markers, availability or provider facts.
Do not claim that this extension can make appointments, take payments or contact
providers.
